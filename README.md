# FRED WHMCS Domain Registrar Module

Manage domains through the FRED registrar integration in WHMCS.

## Features

- Check domain availability and register, transfer, or renew domains.
- View and update domain contact details and nameservers.
- Manage child nameservers and their IP addresses.
- Request EPP authorization codes for domain transfers.
- View, add, and remove DNSSEC records.
- Synchronize domain status and expiry dates with WHMCS.
- Import missing allowed domain extensions through **Sync allowed zones** or the daily WHMCS cron. Manage prices separately in WHMCS.
- Export historical domain inventory when inventory synchronization is enabled.
